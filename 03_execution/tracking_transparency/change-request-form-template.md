# Change Request Form — Template

A Change Request (CR) documents any proposed modification to project scope, schedule, budget, deliverables, or requirements.  
It ensures changes are evaluated, approved, and tracked with full transparency.

---

---

## Change Request Workflow

1. **Submit CR**  
2. **PM reviews for completeness**  
3. **Impact analysis performed**  
4. **Approved By review and decide**  
5. **Decision logged in Decision Log**  
6. **CR implemented (if approved)**  
7. **CR closed**

---

## Notes

- Every CR must be linked to the **Decision Log**.  
- CRs should be used sparingly — only when scope, budget, or timeline change.  
- Minor adjustments should be handled via Issue Log or team coordination.
